This repository contains lab works done for the Introduction to Quantum Computing subject. Here, most of the assignments are done using Pennylane, while qiskit is used in only 2 tasks. 

Quick summary of the labs:

1) 2 Introductions to quantum computing libraries - qiskit and Pennylane.

2) Lab 2 is a simple optimization using Pennylane

3) Lab 3 is a Grover algorithm using Pennylane

4) Lab 5 conatains different optimization algorithms - QAOA, QAA and QUBO to initialize coordinates of the atoms.
